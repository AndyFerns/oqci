# `benchmarks/` — the benchmark and research harness

OQCI's benchmark infrastructure (`final-deliverables-spec.md` §20) runs under
the Stage G protocol locked on 2026-10-20
([`../docs/core_architecture/stage-g-benchmarking-protocol.md`](../docs/core_architecture/stage-g-benchmarking-protocol.md)).
The full description is [`../docs/benchmarks.md`](../docs/benchmarks.md).

```bash
pip install -r requirements.txt
maturin develop --release --manifest-path ../python/Cargo.toml
python -m oqci_bench all --config configs/stage_g.toml --out results/<run-id>
pytest tests -q
```

| Path | What it is |
|---|---|
| `configs/stage_g.toml` | the locked protocol, as data |
| `configs/smoke.toml` | a small CI profile; never reported |
| `oqci_bench/` | the harness: circuits, targets, compilers, correctness, metrics, runner, determinism, interop, mutants, coverage, report, hardware |
| `schema/result.schema.json` | the record schema (§20.3 plus correctness, timing and seeds) |
| `coverage/checkers.toml` | the checker coverage matrix; every cited test is checked to exist |
| `mutants/` | the ten Stage G mutants, the six checkers, and the probe programs |
| `tests/` | the harness's own tests, including deliberately broken outputs the correctness check must reject |
| `results/` | run directories. Only the reference run is committed; `artifacts/` (the compiled circuits) are regenerated by rerunning. |

The IBM hardware experiment is run by its operator with
`python -m oqci_bench hardware snapshot|compile|submit|retrieve`. See
[`../docs/hardware.md`](../docs/hardware.md).
